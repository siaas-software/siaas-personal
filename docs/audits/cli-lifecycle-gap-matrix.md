# CLI lifecycle gap matrix

Baseline: `develop` at `741b531376c93262c5d15354faf14747fbcf97cc`;
audit date: 2026-11-07. See the [audit](cli-lifecycle-audit.md) for architecture,
the proposed command contract, actual validation and unresolved questions;
see the [roadmap](cli-lifecycle-roadmap.md) for phase dependencies.

Evidence IDs link to the audit's [pinned source index](cli-lifecycle-audit.md#evidence-index).
Paths and line ranges below are baseline references. Test paths are repository
relative. “None found” means no focused coverage located in the inspected tests,
not a claim that all conceivable tests were exhaustively executed. Existing tests
listed here were only run when included in the audit's validation table.

**Classification:** IMPLEMENTED = scoped behavior exists; PARTIAL = material gaps
within existing behavior; MISSING = absent in inspected dispatch/call sites;
UNVERIFIED = insufficient execution/acceptance evidence; NOT APPLICABLE = outside
the local desktop scope. **Severity:** High = potential data loss, unsafe ownership
or blocked recovery; Medium = operational ambiguity, failed automation or limited
availability; Low = usability/diagnostics; None = no gap asserted. These are risk
priorities, not claims of observed incidents or security exploitability.
