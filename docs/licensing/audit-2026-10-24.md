# Dependency and asset license audit — 24 October 2026

Original SIAAS Personal code remains **MIT**. No verified finding requires
relicensing the application. This audit inventories the reviewed source; it is
not clearance of every possible packaged binary, model download or service image.

## Scope and reproducibility

- Stable/develop source: `b31e8b8db6db9aae1a5c75c50fc5d4898bf057bb` (same tree as main).
- Structured feature: draft PR #4, `b76f6ff5f547d2f5833df34877d78af911ed9b65`.
- [527 locked application entries](dependency-inventory.json), including dev tools
  and alternative OS binaries. [42 Morphic adapter entries](morphic-dependency-inventory.json).
- The draft adds/changes its lockfile to 662 entries; its four direct additions
  are listed below. It is not installed by stable v1.0.0.

Regenerate an inventory with Node, without installing a scanner:

```sh
node scripts/license-inventory.mjs --modules .
node scripts/license-inventory.mjs --lock services/morphic/package-lock.json --modules services/morphic --out docs/licensing/morphic-dependency-inventory.json
```

Each entry records name, version, direct/transitive scope, license expression,
resolved artifact/integrity, matching installed license-file hashes and required
review. Platform packages not installed locally remain **NOT VERIFIED** at the
license-text level. Hashing a file establishes identity, not legal interpretation.
The inventory does not claim that every locked dev dependency ships to users.

## Native libraries and unresolved findings

**NOT VERIFIED — redistributable native bundle:** the Linux libvips 1.3.4 package
contains libvips 8.18.7 and additional LGPL, MPL, BSD, MIT and custom-license
components (including GLib, Cairo, FreeType, libpng, codecs and fonts support).
Its README/versions.json identify the component versions. A package-level LGPL
label is not a complete license manifest. Corresponding-source delivery,
replacement/relinking conditions and exact bundled notices were not validated
for Windows/macOS/Linux artifacts in this documentation task. Perform this
review before publishing a new binary bundle; this does not establish that the
existing distribution violates a license.

**NOT VERIFIED — draft parser transitives:** `buffers@0.1.1` has no license field
or LICENSE file in the inspected npm artifact. `chainsaw@0.1.0` declares MIT/X11
but no standalone license text was found. Both enter through ExcelJS's transitive
dependency graph. Obtain version-specific provenance/permission, or replace/remove
the dependency in a separately reviewed implementation change before shipping it.
Do not infer permission from a newer package or the parent dependency's license.
`duck@0.1.12` declares the ambiguous label BSD; its actual LICENSE contains a
2-clause BSD text. Preserve that text rather than editing upstream metadata.

**NOT VERIFIED — optional services and models:** Python transitive versions are
not fully locked. Docker was not rebuilt for this audit. Laya's model revision
is not pinned by the application; the historical model-card license does not
prove every future cache. `embeddinggemma:latest` references a model family with
separate Gemma terms; the tag can change. The catalog also discovers user-selected
models dynamically. Qwen2.5 default/reference tags are not permission to distribute
all Qwen, Llama, Gemma, Mistral or other model weights under MIT. Review the exact
artifact, license and usage restrictions. No automatic license acceptance is added.

**NOT VERIFIED — artwork provenance:** the CSS mascot and inline SIAAS mark are
repository code under the project's MIT declaration. The origin/assignment of
raster build icons and inline OS-brand glyphs is not recorded independently in
the inspected files. Preserve them, record the gap and obtain provenance/trademark
review before expanding redistribution; do not invent a stock-asset license.

## Notices and release decisions

THIRD_PARTY_NOTICES.md remains necessary; this inventory supplements it. Verbatim
font and icon notices have been retained. Original license text must accompany
redistributed components where required; a link/inventory alone is insufficient.
Source installation obtains packages with their own metadata, while minified or
bundled distributions require a separate notice-retention check. The draft parser
copies matching license/notice files, but this does not close missing upstream
texts or establish coverage of all Next/Electron bundles.

No model weights, external images, new runtime dependencies or license changes
are introduced here. **Open decision:** resolve parser provenance and native
bundle/source obligations before release. Preserve MIT; do not treat this audit
as authorization to publish or as legal advice about a particular distribution.
