## Distribution gate executed after committing the candidate

`npm run release:source` creates the named source ZIP, installation specification,
six platform manifests, RC and stable-channel entry points, notes, this readiness
record, Windows checklist and SHA256SUMS.txt. The stable scripts continue to resolve
stable Latest; only install-rc uses the explicit candidate tag and isolated RC root.

Before publication run `npm run release:verify-source`. It verifies every payload
SHA-256, exact archive bytes against the release commit, package/lockfile versions,
JSON/TSV manifest agreement, all six runtime hashes against official Node checksums,
and installer bytes. Missing/unexpected/corrupt assets fail closed. Do not infer an
integrity PASS from this document: retain the command's actual output.

After publication run `npm run release:verify-source -- --published`. It downloads
all 12 payloads anonymously, verifies GitHub digests/sizes and exact local bytes,
checks prerelease/draft flags and tag commit, and ensures Latest is still stable.
Publication is not complete until this command and the final Latest/main checks pass.
The published source ZIP SHA-256 is in SHA256SUMS.txt and the release report, rather
than in this self-contained source archive (which would be self-referential).
