# SIAAS Personal v1.1.0-rc.1

Release candidate for isolated local testing, especially on Windows. This is a
GitHub prerelease, not a stable release or a production-readiness claim. Stable
main and the stable installer/update channel remain unchanged. No website
deployment is required or authorized by this release.

## Included changes

- Structured Data Analysis: XLSX/CSV import, multiple worksheets, profiling,
  confirmed column mappings and dataset relationships, validated read-only
  analytical plans, filtering, sorting, grouping, calculations and joins.
  SQLite persistence and TypeScript execution keep calculations local and
  return source evidence. Formula caches are explicitly unverified; formulas,
  macros and arbitrary SQL/code are not executed.
- Knowledge, Chat and Ollama planning integration. Exact calculations use the
  deterministic engine; semantic RAG remains available for descriptive material.
- Official catalog: Computer Science Study, Production Planning and Personal
  Finance. Home Gardening and Software Engineering are retired from the catalog;
  previously created user projects and portable siaas-project-v1 imports remain
  compatible. Models are unset in exported templates.
- Electron 44.9.3, bounded ZIP extraction and parser notice retention. The
  separately prepared website uses Next.js 16.4.3; it is not deployed here.
- Explicit candidate installers with a separate installation/profile directory
  and local launcher, strict version selection and source/runtime integrity checks.

## Installation and local testing

Read [the Windows acceptance procedure](../windows-rc-testing.md) before running
the installer. It covers inspecting an existing installation, a closed-app backup,
SHA-256 verification, Qwen3 8B selection, sample XLSX/CSV files, expected results,
Knowledge, Chat, Actions, updates and rollback. The same guide is attached as
WINDOWS_TESTING.md. Do not delete or reuse the stable profile for the first tests.

Use the attached **install-rc.ps1** (Windows) or **install-rc.sh** (macOS/Linux)
with SIAAS_RELEASE_TAG=v1.1.0-rc.1. Verify the downloaded script against its
GitHub asset digest or SHA256SUMS.txt before executing it. No execution-policy or
antivirus bypass is required. install-siaas scripts retain their stable-channel
behavior and are not the RC installation entry point.

The named SIAAS-Personal-1.1.0-rc.1-source.zip is the installer payload. Do not
substitute GitHub's automatic source archives. rc-manifests.json and .tsv contain
platform-specific source/runtime integrity metadata for x64/arm64 Windows,
macOS and Linux. Manifest coverage is not proof of execution on those platforms.
Node 24.22.0 is provisioned from the official Node distribution; npm dependencies
and Electron are installed and built locally. Internet, several GB of disk and
sufficient RAM are needed. Standard operation requires no Docker, Python,
PostgreSQL, cloud account or remote AI processing. Optional Beta services retain
their separate prerequisites and license terms.

## Verification and limitations

The integrated implementation was checked on Linux with **146 application tests,
16 distribution tests, typecheck, desktop build, Knowledge API and Structured Data
Analysis API checks**. Parser notice verification covers 33 bundled components.
The structured API check uses an Ollama simulator, not real inference. Earlier
Linux packaging and bundled Node/server checks passed at the readiness checkpoint.
These results do not establish Windows/macOS runtime correctness.

- **FAIL / unresolved:** a previous complete real-Ollama analytical workflow
  failed; its root cause was not verified. A subsequent retest was **BLOCKED** by
  environment reset during model download. Real Qwen3 8B end-to-end acceptance
  remains **NOT VERIFIED**. Record failures; never accept invented calculations.
- **BLOCKED:** prior graphical Electron testing encountered Chromium socket
  restrictions. Complete desktop graphical acceptance remains unverified.
- **NOT TESTED:** native Windows, macOS and arm64 runtime; a full clean native
  installation/update/rollback cycle. Distribution fixtures exercise preparation,
  integrity rejection, RC ordering, isolated profile/launcher and rollback; they
  do not replace tests on the user's PC.
- **NOT TESTED:** rollback between two published candidates. On the first RC,
  no previous version is expected. Code rollback is not a database downgrade;
  preserve backups. The existing stable installation stays a separate fallback.
- Source-only publication excludes dependency/runtime binaries, Docker images
  and model weights. Exact native binary source/relinking obligations, optional
  model/image terms and some historical artwork provenance remain **NOT VERIFIED**
  for expanded redistribution. MIT does not license third-party weights/assets.
- npm audits reported **0 critical/high** findings; two **moderate** findings
  concern ExcelJS/uuid. The UUID advisory targets supplied-buffer UUID generation;
  the workbook parser's v4 use is outside that inspected call path. This is a
  reachability assessment, not a claim that the dependency advisory is patched.

## Feedback and stable-release gates

Report problems through the repository Issues page with release tag, OS/architecture,
Ollama/model version, reproduction steps, expected/actual results and sanitized
logs. Sample totals: orders=15; material M1 demand=25 and shortage=5; EUR income=100,
expenses=30, balance=70; USD expense=4 separately. Never attach personal financial
files, confidential recipes, credentials or an entire application profile.

Stable promotion requires real Ollama acceptance, graphical/native platform
testing, lifecycle/data-preservation acceptance and review of any expanded
redistribution obligations. Do not interpret this candidate as permission to
promote main, publish a stable release or deploy the website.
