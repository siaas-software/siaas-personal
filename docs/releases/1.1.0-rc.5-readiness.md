# Candidate readiness

**PARTIAL.** Draft candidate for review, 17 November 2026.

The baseline is develop at 47551f23. Immutable RC4 at d8bf6e61 is eleven release and acceptance commits ahead of that baseline. The application code under src/ is identical between those two inputs. This candidate includes the RC4 browser-test corrections, the new router and offline preparation. Release history reconciliation is still pending under the repository GitFlow.

The final promotion gates include the original Windows 11 CPU-only comparison, native startup and reinstall with a populated profile, sibling RC isolation, and platform-specific acceptance. Existing RC4 results apply to RC4. A Linux headless browser exercises the production desktop HTTP API and SQLite, while the signed-in user's Windows acceptance remains independent.

Run from the candidate checkout with Node 24:

1. Run npm ci and npm ci --prefix services/morphic, then npm test and npm run typecheck.
2. Run npm run desktop:build, npm run test:chat, npm run test:knowledge, npm run test:structured:api and npm run test:ui.
3. Run node tests/structured-api.mjs --hybrid --ui and node tests/structured-api.mjs --hybrid --benchmark. Where needed configure CHROMIUM_EXECUTABLE_PATH for a compatible Chromium. The benchmark uses two excluded warmups and fifteen measured turns per scenario. Read test-results/hybrid/http.json for per-request samples. Production rate limits remain active.
4. Run the archived November 11 Python fixture on that same host for the direct and pure local-model HTTP baselines. Record model digest, CPU residency, first request, p50/p95, correctness, and available resource measurements. Historical Windows numbers are a separate dataset.
5. Run npm run release:source and npm run release:verify-source from a clean, exact candidate commit to regenerate and verify the local twelve-asset inventory. The final publication requires separate authorization.
