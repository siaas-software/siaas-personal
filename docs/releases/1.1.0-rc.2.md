# SIAAS Personal v1.1.0-rc.2

Prerelease for isolated local testing under the user-authorized permanent RC
publication policy (2026-10-28). Stable main, v1.0.0/Latest and the public website
remain unchanged. This is source-based distribution, not a signed native installer.

## Changes

- Structured planning receives authoritative dataset/worksheet/revision, column
  IDs/display names/types, partitions, profiles and bounded example values. YYYY-MM
  values such as 2026-10 are represented as monthly text, not missing dates.
- General greetings/arithmetic bypass inappropriate table planning; broader general,
  document and mixed routing remains model-assisted. Chat-only instructions and
  semantic retrieval retain independent paths.
- Plans are validated before execution, including unknown operands with zero rows.
  Numerical answers and evidence come from the deterministic engine. Model-generated
  missing-column explanations are not repeated as facts; failures return controlled
  errors. The official one-row budget produces **35 EUR** in simulated-planner tests.
- Ordinary streaming requests disable optional reasoning output; planning retains
  schema-constrained JSON and 16,384 context. Cancellation and timeout/model/network/
  invalid-response diagnostics are differentiated. No arbitrary timeout increase.
- Clear CSV/XLSX files automatically detect headers/types/partitions, discover sheets,
  persist metadata and become ready for chat. Ambiguous dates/types/formula caches
  require focused choices. Relationship suggestions require semantic confirmation.
- Knowledge shows readiness/counts/previews. Technical mappings, relationships,
  cardinality, formulas, JSON query editor and exports remain in Advanced Settings.
- White Knowledge/chat/shortcut/footer/avatar inner backgrounds preserve dynamic
  project palettes and semantic controls. Generation uses neutral gray and the
  original animated hand/stars; reduced-motion styling is retained.
- Official hand-and-stars SVG replaces the old S platform icons. PNG, seven-size ICO
  and ICNS have reproducible conversion, provenance hashes and Electron integration.

## Installation

Read attached **WINDOWS_TESTING.md** first. Download **install-rc.ps1**, verify its
GitHub SHA-256 digest, set `SIAAS_RELEASE_TAG=v1.1.0-rc.2` and execute the verified
script. Use `%LOCALAPPDATA%\SIAAS Personal RC Source` and its own `profile` and
`launch-rc.cmd`. Inspect/back up an existing RC installation before updating it.
Do not overwrite the stable profile or bypass PowerShell/antivirus protections.

For Linux/macOS use **install-rc.sh** with the same explicit tag. The install-siaas
scripts remain stable-channel entry points; they do not install RC2. Use the named
**SIAAS-Personal-1.1.0-rc.2-source.zip**, not GitHub's automatic source archives.
Node 24.22.0 and npm dependencies are provisioned locally. Network access and enough
disk/RAM are required for installation and model downloads. No mandatory external
Python, Docker, database server, cloud inference or user authentication is introduced.

## Verification and limitations

Mandatory executable checks and source-distribution integrity must pass before
publication; see **READINESS.md** and repository evidence. Model/embedding regression
suites use simulators and are NOT real Ollama end-to-end acceptance.

**BLOCKED / post-publication manual acceptance:** real Ollama (localhost:11434
refused), Chromium visuals (invalid browser downloads), Linux packaged runtime
(socket restrictions), native Windows executable/icon/installation (no host).
**NOT RUN:** native macOS and real cross-platform install/update/rollback. Do not
reinterpret manifests or PNG/ICO checks as native executable or taskbar validation.
These environmental limits are excluded from RC publication gates by explicit user
policy, and must not be retried until infrastructure materially changes.

The exact original RC1 Windows planner-unavailable trigger remains unverified.
Real Qwen3 CPU intent recognition, timing and instruction following still need the
manual budget/general-chat scenarios. Mixed responses provide deterministic tables
and separate cited document excerpts, not a synthesized analytical narrative.
Locale-formatted numbers may require source/advanced correction or retaining text;
there is no universal locale conversion. Joins are not automatically authorized.
Currencies remain partitioned without an explicit valid conversion source. Formula
caches require consent; macros and external links are not executed.

MIT and existing third-party notices are retained. This release distributes source,
not dependency/runtime binaries or model weights. Existing RC1 licensing/security
limitations are not claimed resolved by these changes. Stable promotion remains a
separate real-world acceptance process.
