# SIAAS Personal 1.1.0-rc.6

Release candidate, not stable. Software + AI: local software handles supported deterministic work; optional local models add interpretation and generation through the existing harness. No mandatory cloud or Ollama dependency is introduced.

## What changes

Portable project templates now preserve optional project-chat configuration using assistant indices instead of device-specific identifiers. Eight official offline presets include PDF maintenance acceptance review and spreadsheet purchase reconciliation. Their coordination and result sharing start disabled; each assistant retains its own instructions, tools and authorized Knowledge.

Existing v1 templates remain importable. New exports use v2 and require a compatible Personal release; RC5 cannot import v2. Unchanged official presets gain the new configuration while customized templates, deletion markers, existing projects and conversations remain preserved. Concurrent user edits are protected during migration. Project UI accepts both template versions.

Templates carry public validated HTTP(S) URL references only, not local files, paths, snapshots, document text, indexes, embeddings, credentials or history. Prepare Knowledge in the destination environment. Example fixtures are synthetic and remain separate from portable configuration.

## Validation and limits

Independent review corrections and executed test evidence are retained in the repository. The mandatory missing-Docker E2E passed unchanged on a genuine Docker-free Debian 12 container with Node 24.22.0. Final candidate validation and asset verification must pass before publication. See [readiness](1.1.0-rc.6-readiness.md) and [Windows acceptance](1.1.0-rc.6-windows.md).

Real Gemma/Ollama inference and native device acceptance remain separate; fixture arithmetic and simulated tools do not prove model reliability. No MCP, generative media, permission gateway, execution-trace platform, remote indexing providers or Intelligent Project Builder is included. RC5 and stable releases remain unchanged.
