# SIAAS Personal 1.1.0-rc.5 candidate notes

Draft for review. The existing desktop chat now handles the following requests without a selected model, embeddings, or an inference request. Enter `/help` or `/aiuto` for examples.

| Request | Result |
| --- | --- |
| What is 2 + 2? | A decimal arithmetic result |
| What is the total budget in budgets.csv? Show the result, currency, and number of rows used in the calculation. | Sum and count of nonmissing mapped values per configured partition, with source and warnings |
| Find duplicates in duplicates.csv | Matching records across all columns, up to eight comparison keys, within output limits |
| search documents: maintenance | Labeled excerpts from enabled, prepared local documents |
| cerca siti: manutenzione | Excerpts from previously acquired, enabled website snapshots |

Sums require a unique sheet and an exact numeric column name. Filters and joins can use the advanced query editor or local model-assisted planning. A rejected plan or planner timeout produces no calculation. The downloadable report retains the plan and source evidence. The free desktop app uses its existing local data store.

Text PDFs, DOCX, TXT and acquired pages can use a keyword index. Later reindexing can add embeddings. Scans require external OCR. Docling is under evaluation. CSV and XLSX continue to use the structured parser. See the [release gates](1.1.0-rc.5-readiness.md).

## Integrated candidate update — 20 November 2026

Direct assistant chat and optional project chat share one execution service and each assistant's Hybrid Router. Project orchestration is explicitly configured, sequential and limited to eight steps, with separate history, opt-in text handoff, progress, cancellation, current membership checks and scoped Markdown reports. **List Sources** is a native read-only Action usable without Ollama. Other Actions preserve model behavior.

Local agent eligibility uses reported completion/tools capabilities and compatible runtime rather than an 8B parameter threshold. Planner timeouts are bounded and configurable. Incomplete generations retain partial output and report errors. PDF text extraction is supported; PDF filling and autonomous model-driven project supervision are not implemented.

This is an unpublished draft candidate. See [20 November source integration evidence](../rc5-integration-2026-11-20.md) and [readiness](1.1.0-rc.5-readiness.md). No merge, tag, release publication or public download change is authorized by these notes.
