# Windows 11 acceptance for RC5

Use a disposable per-user environment with a verified, explicitly staged candidate and an isolated application root. Record source SHA, archive digest, Windows build, CPU, RAM, Node, Ollama and the model digest.

1. Save RC4, stable and unrelated profile sentinels. Install RC5, launch it, create an assistant without selecting a model, link the budget and duplicate fixtures, and submit the questions in the [candidate notes](1.1.0-rc.5.md).
2. Record the visible answer, verified source, partition, counted rows, duplicate warnings and persisted history. Close the app, relaunch and reinstall. Verify the data in each installation independently.
3. Change a linked file and try the same question before refreshing it. Query from an assistant in a different project. Disable a prepared website and repeat its keyword search while offline.
4. Select qwen3:8b and use the same composer. Observe Ollama requests during deterministic submissions, a bounded model-planned calculation, a generation and a failed planner attempt.
5. Repeat the original CPU-only comparison on the reference PC, with two excluded warmups and fifteen measurements. Compare the candidate with an isolated RC4 installation. Record first request, steady-state latency, correct results, request and token counts. Save ollama ps output while the model is loaded.

Check release script digests and the appropriate source/runtime manifests before final authorization. Record unsupported or untested operating systems separately.
